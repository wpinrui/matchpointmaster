# Crest SVG Templates

This directory contains SVG templates for crest shapes. These templates should:
- Have a viewBox of "0 0 200 200"
- Use fill="currentColor" or fill="#PRIMARY", fill="#SECONDARY", fill="#ACCENT" placeholders
- Have stroke="#000000" for black outlines
- Be optimized SVG files

## Outside Shapes
- circle.svg
- shield.svg
- wreath.svg
- square.svg
- diamond.svg
- hexagon.svg
- oval.svg
- star.svg

## Inside Shapes
- torch.svg
- book.svg
- star.svg
- cross.svg
- laurel.svg
- crown.svg
- scroll.svg
- quill.svg
- none.svg (or just a simple circle)
